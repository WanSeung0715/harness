# 하네스 저장소

공통 작업 지침과 프로젝트별 하네스를 관리하는 저장소입니다. 저장소 루트의 `AGENTS.md`가 공통 기준 색인이며, 프로젝트 전용 하네스는 각각의 디렉터리에 둡니다.

## 프로젝트 하네스

- [홈페이지 하네스](homepage-harness/AGENTS.md): 홈페이지 프로젝트의 작업 흐름, 보안, Cloudflare, SEO·성능, 검증 지침

새 프로젝트를 추가할 때 `<project>-harness/` 디렉터리를 만들고 해당 프로젝트에 특화된 규칙만 분리해 관리합니다. 비밀정보와 계정·리소스 식별자는 저장하지 않습니다.
